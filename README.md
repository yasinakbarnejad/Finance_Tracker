# Finance Manager API & Dashboard

A full-stack personal finance management application built with FastAPI, Pandas, and Plotly. 
Designed for users who want to track expenses, incomes, and investment portfolios with 
Jalali (Persian) date support.

## 🚀 Features
- **User Authentication:** Sign up and log in (stored locally).
- **Transaction Tracking:** Log daily expenses and incomes with Persian date picker support.
- **Investment Portfolio:** Search real-time investment funds, buy/sell stocks, and track profit/loss.
- **Visual Reports:** 
  - Monthly income vs. expense comparison.
  - Category breakdown (Pie charts).
  - Net worth history.
- **No Frontend Framework:** Pure HTML/Jinja2 and CSS to keep the focus on backend logic.

## 🛠️ Tech Stack
- **Backend:** FastAPI, Python 3.10+
- **Data Processing:** Pandas
- **Visualization:** Plotly Express
- **Templating:** Jinja2
- **Database:** JSON & CSV (File-based)
- **Date Handling:** jdatetime
